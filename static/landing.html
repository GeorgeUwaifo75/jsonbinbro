Connect in seconds

Every request uses your user_id and api_key. Here are two quick examples to get you started.

JavaScript (fetch)
// 1) Create a new bin
const userId = "YOUR_USER_ID";
const apiKey = "YOUR_API_KEY";

const create = await fetch(
  `/api/bins?user_id=${userId}&api_key=${apiKey}`,
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      name: "Favorites",
      data: { colors: ["blue", "purple"] },
      is_private: true
    })
  }
);
const { id } = await create.json();

// 2) Read it back
const read = await fetch(
  `/api/bins/${id}?api_key=${apiKey}`
);
const bin = await read.json();
console.log(bin.data.colors); // ["blue", "purple"]
Works in browsers, Node 18+, Deno, and Bun.
cURL & Python
# Create a public bin with cURL
curl -X POST \
  "https://yourdomain.com/api/bins?user_id=YOUR_ID&api_key=YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Config",
    "data": {"theme": "dark", "lang": "en"},
    "is_private": false
  }'

# --- Python (requests) ---
import requests

BIN_ID = "65f...abc"
KEY    = "YOUR_API_KEY"

r = requests.get(
    f"https://yourdomain.com/api/bins/{BIN_ID}",
    params={"api_key": KEY}
)
print(r.json()["data"])
Replace the domain with your deployment URL.

Frequently asked questions

Still curious? Email us at geocorpsys@gmail.com.

What is a "bin"?

A bin is a single JSON object stored on our servers. You create it with a POST request, get a unique ID back, and can then read, update, or delete it whenever you like. Think of it as a tiny document in a database — without setting up a database.

Is there a free tier?

Yes. Every new account gets 300 free requests on signup — enough to build a small project or evaluate the service. You can upgrade any time with PayStack to add 2,000, 5,000, or 10,000 more requests.

How do I pay?

You have three options:

1. PayStack (NGN): Log in, open the dashboard, click Payment in the navigation bar, choose a plan, and complete checkout. Your request limit is updated automatically as soon as payment is confirmed.

2. USDT via Telegram TON Wallet: Send the USDT amount for your chosen plan to our Telegram TON Wallet address shown in the Pricing section, then email the transaction hash and your username to geocorpsys@gmail.com.

3. Direct Bank Transfer (GTBank): Transfer the NGN amount for your chosen plan to GTBank · 0152935862 · George Uwaifo, then email your username, the plan name, and the transfer receipt/session ID to geocorpsys@gmail.com. We credit your account within a few hours.

Where do I find my API key?

Your API key is generated automatically when you register. It's returned when you log in and stored in your browser for the dashboard. You can also retrieve it from the dashboard's user info or profile area.

Can I share a bin publicly?

Yes. Bins are public by default. Set is_private: true when creating or updating a bin to restrict access to requests made with your API key.

Do purchased requests expire?

No. Purchased requests are added permanently to your request limit. Your counter only goes down when you make a create, update, or delete call.

What if I exceed my request limit?

The API will return 403 Forbidden with a clear message asking you to upgrade. Just open the Payment dialog in your dashboard and choose a plan to add more requests instantly.
